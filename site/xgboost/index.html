XGBoost by hand

Build 3 trees by hand, each fixing the last one's mistakes. Then boost 97 more.

Training data

10 rows · 5 features · 1 response

! Row 7 is an outlier: strong on every feature, but scored 25 (sick on exam day). Residual = actual − predicted.

1

Start with one guess

Every student is predicted the average score, 55.4. The gap between actual and predicted is the residual.

2

Fit a tree to the errors

Each new tree is trained on the residuals the trees before it left behind. Rows with big errors dominate the split gain.

3

Add it, shrunk

The tree's output is multiplied by the learning rate η = 0.3 and added on. Then repeat, 100 times in total.

Unlike a random forest: no bootstrap sample and no random features (XGBoost's defaults use every row and every feature), and the trees are not independent. Tree 2 can't be built until Tree 1 is finished, because it learns from Tree 1's mistakes.
